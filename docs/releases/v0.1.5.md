# Blubber v0.1.5 — projects that stay projects

This release fixes the first customer-reported gaps in Blubber's custom-folder workflow.

## What changed

- **Add Project** registers one existing repository as one project. Its `src`, `docs`, `public`, and other internal folders are no longer promoted into separate project cards.
- **Add Folder** keeps the existing container workflow for a directory that holds several repositories.
- Paths saved by v0.1.4 are classified automatically after updating, so customers who already selected a repository do not need to remove and re-add it.
- Every custom registration now has a **Forget** control. It removes the folder from Blubber only; nothing on disk is deleted and the rest of the dashboard is untouched.
- Single-project roots now retain the correct terminal path, metadata, activity, and session identity.

## Updating

Blubber v0.1.3 and newer checks for this release automatically. The update downloads in the background and prompts when it is ready to install.

Older v0.1.0–v0.1.2 installations still require one manual download because those versions did not include the updater.

Download `Blubber.Setup.0.1.5.exe` from the assets below and run it. The Early Access installer is still unsigned, so Windows may show an “unrecognized app” warning; choose **More info → Run anyway**.
