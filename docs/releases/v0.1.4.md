# Blubber v0.1.4 — reliable projects and a bigger terminal

This release turns direct customer feedback into two practical improvements for long sessions.

## What’s new

- **Add any project folder.** Projects now has a native Windows folder picker for repository containers outside Blubber’s default locations.
- **Folders survive restarts.** Saved project roots are stored durably and restored whenever Blubber launches.
- **Project activity stays accurate.** Repositories with the same folder name under different roots keep separate identities and activity.
- **A terminal that gets out of your way.** The Terminal screen now has an expand/restore control that reclaims the sidebar and lower dashboard space.
- **Clean-slate onboarding is reliable.** Entering from an empty Claude workspace now completes the connection step correctly.
- **Safer local access.** Custom roots are path-contained, picker registration is main-process authorized, and Blubber’s internal capability tokens never reach Claude or installer child processes.

## Updating

Blubber v0.1.3 downloads this update automatically in the background. Choose **Restart now** when prompted, or choose **Later** and it will install when you quit.

Versions v0.1.0 through v0.1.2 cannot update themselves and require one manual install.

## Manual install

Download `Blubber.Setup.0.1.4.exe` from the assets below and run it.

The installer is still unsigned, so Windows SmartScreen may say “Windows protected your PC.” Choose **More info**, then **Run anyway**.

SHA256: `47E11A5A98B73ECA69666C19707E6D9B7F093CF530A87ABEA0E1A7F6287CC47A`

The `latest.yml` and `.blockmap` assets are for Blubber’s updater; manual installers do not need to download them.
