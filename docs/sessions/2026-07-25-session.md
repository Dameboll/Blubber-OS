## Key Decisions
1. **Installer not kit-gated** — the kit marker lives inside `~/.claude`, the directory whose absence defines that screen, so gating was structurally impossible, not just unwise.
2. **Native installer over npm** — the packaged app ships its own Node, so npm doesn't exist on a clean box.
3. **Yield + slice the indexer** rather than move it to a worker thread — same outcome, far smaller blast radius.
4. **Didn't run the real installer** against Dame's machine — proved the command shape instead, logged the gap honestly.
